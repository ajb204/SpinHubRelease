# Stages 116-119

## Stage 116 - INDIANA quarantine

The historical `INDIANA/cellDiff.py` backend is disconnected from the active
application; its only repository reference was a commented import in the
already-quarantined `legacy/pseudo2d_old.py`.  The implementation is preserved
at `legacy/indiana/cell_diff.py`.  The historical path is a compatibility
facade so external imports do not break.

This is deliberately a quarantine, not deletion: scientific functionality may
be recovered later behind the modern pseudo-axis/diffusion service boundary.

## Stage 117 - compatibility surface contract

The remaining root modules and `misc/` modules are intentional compatibility
surfaces.  Active packages must use canonical `app/`, `analysis/`, `domain/`,
`gui/`, `processing/`, `project/`, and `workflow/` locations instead.

## Stage 118 - legacy ownership audit

`Frames/`, the historical root application modules, MANCO/CATIA prototypes,
and INDIANA are now compatibility or quarantine surfaces rather than active
architectural owners.  Future work should remove a compatibility surface only
when external compatibility is intentionally broken in a release.

## Stage 119 - clean distribution checkpoint

Generated Python caches and pytest caches are excluded from the checkpoint
archive.  Regression, compile, and AST checks are run before packaging.

## Stage 118 - pseudo-axis presentation boundary

The pseudo-axis table model remains in `domain/pseudo_axis.py`, but its wx table
viewer now lives in `gui/dialogs/pseudo_axis.py`.  CPMG and Decay import the
viewer from the GUI layer.  A regression test prevents wx from leaking back
into the pseudo-axis domain module.
