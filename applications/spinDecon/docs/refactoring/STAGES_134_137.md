## Current position

The package/file-layout refactor is effectively complete. Remaining work is compatibility-dependency retirement and final validation rather than structural relocation.

Largest remaining textual `tabOne` hotspots are Peak Review (28), Slice2D (22), Slice4D (19), Slice1D (16), PeakFit (16), MAGMA workspace (15), Projection (14), Pseudo2D (11), and Phasing (11). The old uSTA GUI is no longer considered an active hotspot: it is quarantined legacy code. Likewise, old `conn_data`-based NOE/connectivity routines are not to be modernised into the peak model. Useful functions should later be recovered behind a dedicated connection/NOE service referencing authoritative Full Peak List identities.
