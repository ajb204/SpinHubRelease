# Stages 145-147 - final active workspace boundary cleanup

## Stage 145 - Slice2D service-only construction

The active Slice2D workspace no longer stores the historical `tabOne` workspace.
Construction resolves `ApplicationContext` and always creates/uses `SliceService`.
Reference peaks, threshold, symmetry and spectrum path are obtained through the
service. Historical NOE/MAGMA/`conn_data` comments remain only as quarantined
legacy context and are not active peak ownership.

## Stage 146 - PeakFit final workspace-handle cleanup

`peakFitFrame` no longer stores `self.tabOne`. The remaining live parent-spectrum
axes query was moved behind `PeakFitService.visible_axes`. Shape values and fitting
payloads remain service-owned. Old source-contract comments are retained only where
they document historical behavior.

## Stage 147 - Peak Review service-only scientific path

Peak Review now always has a `PeakService`, including standalone/legacy
construction. Spectrum resolution, threshold, topology fallback, bore payload,
view labels, projection/deconvolution payload and canonical peak persistence are
all routed through that service. Source-sensitive regression tests were updated to
protect the service boundary rather than obsolete direct workspace calls.

The authoritative Full Peak List rule is unchanged. `conn_data`, MAGMA, Slice4D,
uSTA and historical NOE/connectivity code remain legacy/quarantined.
