# Stages 125-126

## Stage 125 - canonical NMR workspace name in the application shell

`app/notebook.py` now uses `self.nmr_workspace` as the canonical internal name
for the main NMR workspace.  The historical `self.tabOne` attribute is retained
only as a backwards-compatible public alias for plugins and older workspaces:

    self.tabOne = self.nmr_workspace

Application-shell save/load, workflow routing, noise-blit handling, service
composition, and child-workspace construction now use the canonical name.
Source-contract tests were updated to protect the new boundary rather than the
historical implementation detail.

This is intentionally not a removal of the legacy bridge yet: older specialist
workspaces still accept/use `tabOne`, and `ApplicationContext.legacy_nmr_workspace`
remains the explicit migration bridge while those consumers are converted.

## Stage 126 - misc compatibility boundary guard

Audited active packages for imports from `decon.misc`. No active package imports
the compatibility `misc/` surface. Added an AST regression guard covering
`app`, `gui`, `analysis`, `project`, `workflow`, `processing`, `integrations`,
and `domain` so compatibility helpers cannot silently become dependencies again.
